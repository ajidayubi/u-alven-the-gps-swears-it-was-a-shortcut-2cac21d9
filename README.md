One line of plain text, at most 200 characters: the GPS's excuse, in its own voice, for sending the driver down the wrong road. Judged head to head by a comedy judge, funniest line takes the top reward.

Our line: "The map said that lake was a road, and I don't argue with the map — I just repeat it louder. Ask the fish: they heard me coming." The program writes that one line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
